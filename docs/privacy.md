# 安能助手隐私权政策

最后更新：2026-09-17

安能助手是浏览器侧栏智能助手。本政策说明扩展在提供问答功能时会处理哪些信息。

## 收集的信息

为了基于当前页面回答问题，扩展会在你主动提问或使用划词/右键功能时读取：

- 当前标签页的标题和网址
- 你选中的文字、图片、链接，或当前页面的可读内容
- 你主动上传或选中的图片、PDF 文本，以及语音输入转写结果
- 你在侧栏中输入的对话内容
- 当你询问接口、Network、Console、请求或响应数据时，扩展临时采集的网络请求与控制台快照

调试快照会在发送前对常见令牌、密码、Cookie、认证头和敏感查询参数进行脱敏。扩展不会记录鼠标轨迹或击键。

## 如何使用

上述信息仅用于完成你发起的问答、语音转写、识图、PDF 阅读或调试分析。扩展的 Service Worker 直接把必要内容发送到配置的模型服务；会话和设置保存在浏览器本机存储中。

## 不会做什么

- 不会向第三方出售用户数据
- 不会把用户数据用于与侧栏问答无关的目的
- 不会用于信用评估或贷款
